# 🏥 Appointment Management System

A full-stack MERN (MongoDB, Express, React, Node.js) appointment management platform with real-time updates and role-based access.

## Project Overview

- **Backend**: Node.js & Express REST API with Socket.IO
- **Frontend**: React 18 + Vite with Tailwind CSS
- **Database**: MongoDB with Mongoose ODM
- **Real-Time**: Socket.IO for live appointment notifications
